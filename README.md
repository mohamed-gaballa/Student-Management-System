# 🎓 Student Management System

🚀 A modern and interactive Student Management System
built with HTML, CSS, and JavaScript.

## ✨ Features

- 🎨 Modern Dark UI Design
- ➕ Add New Students
- ✏️ Edit Student Information
- 🗑️ Delete Students
- 📋 Display Student Data
- 🔢 Total Students Counter
- ⚡ Interactive User Experience

## 🛠️ Built With

- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript
- 🧠 DOM Manipulation

## 💡 CRUD Operations

- 🟢 Create — Add Students
- 🔵 Read — View Students
- 🟡 Update — Edit Students
- 🔴 Delete — Remove Students

## 🎯 Project Purpose

This project was developed to practice JavaScript,
DOM manipulation, and CRUD operations.
